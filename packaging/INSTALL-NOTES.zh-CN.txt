Spatial ASIO 0.1.1 预览版

仅保留：原生对象捕获 → 点声源渲染 → ASIO。
已包含 .NET 桌面运行时、Python 和 Frida，无需另行安装这些环境。

安装器支持 Windows 10 2004（19041）及更新的 Windows x64。
实际空间对象捕获仅限通过验证的 audiodg.exe 版本。
其他版本可以安装并配置程序，但不能保证捕获可用。请先执行“检查捕获兼容性”。
不支持 ARM64、32 位 Windows 或受保护的音频宿主。

运行程序时需要管理员权限。请先安装设备厂商的 64 位 ASIO 驱动。
在游戏实际使用的 Windows 播放端点上启用 Windows Sonic，然后重新启动游戏。
本程序不包含 ASIO 设备驱动，不安装虚拟音频驱动，不修改系统安全配置。

安装包尚未进行商业代码签名。Windows 可能显示未知发布者。
本程序并非 Dolby 官方产品，也不包含 Dolby 或 Studio One 的二进制模块。
