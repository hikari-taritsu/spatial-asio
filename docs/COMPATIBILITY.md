# 兼容性边界

安装器最低 Windows 10 2004 / 19041，原生 x64；不支持 ARM64 或 32 位系统。GUI 与引擎采用独立运行环境。此最低版本是构建目标，不代表每个系统版本已经实测。

捕获模块读取 Windows 音频宿主的内部对象结构，因此必须验证**实际文件哈希**。Windows 版本号相同，也不能替代哈希检查。

| audiodg.exe SHA-256 | 状态 |
|---|---|
| `b97353300a4e0c68257bb5a2554afaa3733609c739368febc36a5f63ef47a44f` | 本机 10.0.26100.8875；原有 4 对象/500 周期夹具验证，后续用户确认游戏链路可工作 |
| `3dd24fe6faf0b56f99d5b00f24687b5f3b3e76e15b219e23f0963114a0dce9a5` | Spatial Pip 已有配置标记；本次独立版本未重新测试该系统 |
| 其他哈希 | 拒绝捕获；不作兼容承诺 |

需要管理员权限、未受保护的 audiodg 宿主、当前仅支持单宿主自动选择。检查过程不会关闭系统保护。请不要通过改哈希/地址来绕过验证。新增支持需要核对符号与结构、运行受控位置/增益/PCM/生命周期夹具，并确认卸载挂钩恢复原始字节。

Windows Sonic 必须作用于游戏实际使用的端点。普通立体声应用不会凭空产生空间对象。应用收到的是 Windows 提供者前的基础对象数据；不承诺获取专有扩展元数据。

安装包目前未进行商业代码签名。不存在“一个安装包永久覆盖所有未来 Windows 版本”的保证。
